## 🔥 Featured Projects

### 🚨 [AsistencIA](https://github.com/germangarest/TFM-AsistencIA)
Real-time incident detection system using computer vision to identify accidents, fires, and fights.
- **Technologies**: YOLOv8, NLP, Streamlit, LLM integration
- **Features**: Video analysis, emergency chatbot, training module, email alerts
- **Results**: Multi-modal system with high accuracy detection (91% for accidents, 93% for fires)
- **Website**: [Website](https://asistencia.germange.com/)

### 🎨 [RealGEN](https://github.com/germangarest/stable_diffusion_realistic)
Web application for generating photorealistic images using interactive controls.
- **Technologies**: Stable Diffusion API, Streamlit, Python
- **Features**: Parameter customization, prompt generation, image saving
- **Website**: [Website](https://realgen.germange.com/)

### 🏨 [Hotel Analytics](https://github.com/germangarest/hotel_analytics)
Comprehensive hotel management platform with ML predictions.
- **Technologies**: Streamlit, Scikit-learn, Pandas
- **Features**: Cancellation prediction (84% accuracy), price optimization (R² 0.75), hotel star classification
- **Website**: [Website](https://hotel-analytics.streamlit.app)

### ✍️ [Story Generator](https://github.com/germangarest/generador_historias_API)
Interactive story generation app using various LLMs.
- **Technologies**: Gradio, LLMs (Llama, Gemma, Mistral, Qwen)
- **Features**: Customizable characters, settings, plot elements, creative parameters
- **Results**: Professional-quality creative writing with downloadable stories
- **Website**: [Website](https://story.germange.com/)

### 🧬 [ML-Diabetes](https://github.com/germangarest/ML-Diabetes)
Diabetes prediction system using machine learning classification.
- **Technologies**: RandomForest, Scikit-learn, Pandas
- **Features**: prediction (no diabetes, diabetes)
- **Website**: [Website](https://diabetes.germange.com)
